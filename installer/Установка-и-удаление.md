# Установка и удаление LazyLinuxSSH в Windows

## Что подготовлено

В каталоге `installer` проекта находятся:

- `build-installer.ps1` — публикует приложение для Windows x64 и запускает создание установщика;
- `LazyLinuxSSH.iss` — конфигурация Inno Setup: установка, ярлыки, запись в списке установленных приложений и автоматический деинсталлятор.

## 1. Установить инструменты сборки

На рабочем ПК нужны:

1. .NET 8 SDK: https://dotnet.microsoft.com/download/dotnet/8.0
2. Inno Setup 6 или 7: https://jrsoftware.org/isinfo.php

Сам .NET Runtime на компьютерах пользователей не потребуется: сборка self-contained уже содержит необходимые компоненты.

## 2. Собрать установщик

Откройте PowerShell в корне проекта:

```powershell
cd C:\Users\301FPS\Desktop\lcg
powershell -ExecutionPolicy Bypass -File .\installer\build-installer.ps1 -Version 1.1.0
```

Результат:

```text
artifacts\installer\LazyLinuxSSH-Setup-1.1.0-win-x64.exe
```

Именно этот файл нужно передавать пользователям. Для следующей версии укажите новый номер, например `-Version 1.1.1`. Номер из `-Version` попадает в установщик и отображается в статус-баре приложения справа (перед SSH.NET).

### Если появляется NU1301

`NU1301` означает, что компьютер не смог обратиться к `https://api.nuget.org/v3/index.json`. Проверьте интернет, DNS, прокси, VPN и правила брандмауэра, затем повторите команду. Это не ошибка C# или Inno Setup. Не открывайте `.iss` напрямую: сначала скрипт должен выполнить `dotnet restore` и `dotnet publish`, иначе установщик не получит файлы приложения.

## 3. Установить приложение

Запустите созданный `LazyLinuxSSH-Setup-1.1.0-win-x64.exe`, выберите каталог установки и при необходимости отметьте создание ярлыка на рабочем столе.

По умолчанию используется установка для текущего пользователя, без обязательных прав администратора. Inno Setup также предложит выбрать режим с повышенными правами.

## 4. Удалить приложение

Деинсталлятор создается автоматически вместе с установщиком. Удаление доступно любым способом:

- **Параметры → Приложения → Установленные приложения → LazyLinuxSSH → Удалить**;
- через классическую панель управления «Программы и компоненты»;
- запуском `unins000.exe` из каталога установки LazyLinuxSSH.

База подключений, зашифрованные секреты и настройки в `%APPDATA%\LazyLinuxSSH` при удалении сохраняются, чтобы переустановка не приводила к потере данных. Если требуется полное удаление, удалите этот каталог вручную после деинсталляции.
