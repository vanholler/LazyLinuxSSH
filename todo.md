## 1. Архитектура, данные и SSH
- [x] Решение .NET 8 / C# 12: Core, Infrastructure, Desktop и тесты; MVVM, DI, Clean Architecture.
- [x] SQLite через EF Core, группы и CRUD подключений, создание группы «на лету».
- [x] Шифрование секретов: DPAPI на Windows, AES-GCM на остальных ОС.
- [x] SSH.NET, аутентификация паролем и ключом, PTY, ShellStream и асинхронный ввод-вывод.
- [x] Stateful ANSI/VT-буфер и рабочее отображение терминала через AvaloniaEdit.
- [x] KeepAlive, heartbeat, обработка разрывов и reconnect overlay.
- [x] Независимые сессии, постоянные терминальные ячейки и режимы 1×1, 2×2 и 4×4.
- [x] Тёмная и светлая темы с плавной сменой значка луны и солнца.
